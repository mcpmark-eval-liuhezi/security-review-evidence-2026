# Security Review Checklist 2026

## Scope
- Maintainer account repositories
- Release tags and published releases
- CI workflows and automation

## Pre-review checks
1. Inventory open secret scanning alerts
2. Review dependabot alerts
3. Confirm branch protection on active repositories
4. Check release and tag hygiene
5. Review collaborator access

## Sign-off
- Owner sign-off recorded in the tracking issue before the review meeting
